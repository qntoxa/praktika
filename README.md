# Единая автоматизированная система авторизации и предоставления демо-доступа

Данный проект представляет собой веб-приложение на языке **Golang**, предназначенное для регистрации корпоративных пользователей, валидации их данных и автоматического предоставления демонстрационного доступа к сервисам компании. Интерфейс системы разработан в фирменном корпоративном стиле **ПАО «Ростелеком»**.


##  Ключевые особенности и архитектура

Проект разработан в соответствии с современными требованиями к высоконагруженным B2B-сервисам:

1. **Асинхронная отправка писем (Concurrency):** Процесс работы со сторонними SMTP-серверами вынесен в отдельные потоки (**горутины**). Благодаря этому бэкенд мгновенно возвращает пользователю страницу успешной регистрации, а тяжелый процесс отправки почты выполняется в фоновом режиме.
2. **Настоящая SMTP-интеграция:** Реализована отправка полноценных HTML-писем через протокол SMTP (с поддержкой STARTTLS, авторизацией по токенам приложений и кодировкой UTF-8 для корректного отображения кириллицы).
3. **Комплексная валидация:** Система не просто проверяет заполненность строк, но и вычисляет подлинность ИНН на основе контрольных сумм по алгоритмам ФНС РФ.

---

## 🛠 Технологический стек

* **Backend:** Язык программирования **Golang 1.21+** (стандартная библиотека `net/http` для максимальной производительности без тяжелых сторонних фреймворков).
* **Frontend:** HTML5 (адаптивная верстка, сложные радиальные и линейные градиенты, симуляция векторной графики логотипа).
* **Шаблонизатор:** `html/template` (встроенный в Go безопасный движок шаблонов).
* **Протоколы:** HTTP, SMTP (STARTTLS).

    Объяснение алгоритмов бэкенда
1. Валидация ИНН (Алгоритм ФНС)
Для верификации контрагентов в бэкенд заложен алгоритм проверки контрольных цифр. Математически ИНН юридического лица (10 знаков) и индивидуального предпринимателя (12 знаков) проверяется умножением каждой цифры на определенный весовой коэффициент.
Если рассчитанный остаток совпадает с последней цифрой введенного ИНН, система считает организацию существующей. В противном случае бэкенд прерывает регистрацию и возвращает пользователю ошибку без отправки почты.
2. Фоновое логирование и уведомление
При успешной отправке формы Go-сервер генерирует уникальный криптографический SHA-256 токен сессии (первые 8 символов), формирует безопасную ссылку и инициирует отправку двух писем:
Пользователю: Красивое HTML-письмо с приветствием и персональной ссылкой на демо-стенд.
Администратору: Техническое извещение со спецификацией новой компании (Имя, ИНН, Email заявителя, таймстамп) для контроля лидов.

    Порядок запуска и тестирования
Настройка конфигурации почты
Перед запуском откройте файл cmd/server/main.go и в начале функции main() заполните переменные вашей технической почты:
    smtpEmail    := "your-email@yandex.ru"      // Почта-отправитель
    smtpPassword := "your-app-password"      // 16-значный пароль приложения
    adminEmail   := "admin-alerts@yandex.ru"   // Почта для логов админа

Запуск: go run main.go
Откройте в браузере интерфейс авторизации: http://localhost:8080

Сценарии ручного тестирования
Тест валидации: Попробуйте ввести случайные цифры в поле ИНН (например, 1234567890) — система выдаст ошибку. Для успешного теста используйте реальный ИНН любой компании (например, ПАО "Ростелеком": 7707049388).
Тест панели администратора: Доступен по адресу http://localhost:8080/admin. Таблица наглядно демонстрирует записи, находящиеся в оперативной памяти бэкенда. При перезапуске процесса в консоли память полностью очищается.
